# CodeSync – Frontend UI Demo (Static Version)

This repository contains a **fully static HTML/CSS/JS demo** of the CodeSync application.  
The goal of this project is to visually represent the main features of CodeSync for academic submission, documentation, and demonstration purposes.

**Important:**  
This is **not** the real Base44-powered application.  
All backend features such as authentication, AI assistant, project saving, and code execution **are not part of this static demo**.
